## The two things that need a decision before more code

**1. Slice 10b needs a ruling, and the obvious implementation inverts the Operator's own instruction.**
Full analysis in the comment above dated 2026-08-21. Short form: the device mute is read at the
DECISION point (`notify.go:97`), not at send — so muting a device produces no notification at all,
and slice 10a's send filter never runs. Adding an owner column to the preference table cannot fix
that. Honouring the ruling means moving the mute to the send loop, which reverses a stated design
decision and changes what `qn.12`'s `device_off` status means. **Narrowing the ruling — the admin's
mute suppresses globally — is the cheaper answer and is a legitimate one.**

**2. The overwrite measurement is still owed and needs slice 9 plus a phone.** Whether an
authenticator REPLACES a discoverable credential sharing `(rpId, user.id)`. quince#1398 removed the
reliance, so nothing is blocked — but it is the claim that made quince#1393 urgent. The W3C
`authenticatorMakeCredential` text would not retrieve in full from a session (two attempts, both
truncated); MDN describes duplicates being prevented by `excludeCredentials`, **which D4.1 rules the
enrolment ceremony must not send** — so that guard is deliberately absent on exactly this path. The
experiment: enrol a scoped credential on a phone already holding the admin's passkey, see what
survives. Deploy to the lab stand and post ≤5 steps; do not hand it back as "owed to hardware".

## What is not obvious from the diffs

**Five NULL-means-admin defaults, and they are deliberate, not drift.** `sessions_auth.credential_id`
(0014), `passkeys.scope_udid` (0015), `passkeys.user_handle` (0016),
`push_subscriptions.scope_udid` (0017), and `passkeyUser.name`. Each is accepted on the same
argument: it is TRUE of every row that exists, so the migration is additive with no backfill — and
the Go layer refuses to guess for NEW rows. `store.InsertPasskey` takes scope as a **positional
argument of a type whose zero value is invalid**, so forgetting it is a compile error. That pattern
came out of quince#1361's review and is now house style for this rung; keep it.

**Two totality assertions panic at construction**, in `httpapi/scope_routes.go` and
`scope_resource.go`. A route registered without a scope decision, or a `scopedOwnDevice` route
without a device resolver, fails every API test by name. **Do not soften these into logged
warnings** — the first one caught five routes that a hand-built inventory missed twice.

**`unresolvableToday` is empty and should stay a named map.** It is where a deliberate
fail-closed exception is recorded if one is ever right again.

**Authorization is four shapes, not one check**: refuse · resource-check · response-filter · and a
**body**-check for `POST /api/jobs`, whose device is in the payload rather than the path. That last
one is the one a path-reading guard waves through, and it starts a backup.

**The socket is not covered by anything the routes do.** `/api/ws` bypasses the API chain by design,
so `authGuard` never runs for it. It has its own principal, its own filter, and re-resolves on the
ping tick — which also ends sockets outliving their sessions, a bug that predated the rung.

**`user.name` is cosmetic; `user.id` is identity.** D2.1's naming fix was treating a symptom, and
D2.3 fixed the cause. `ErrAmbiguousScopeDevice` was deleted rather than patched. If a future change
makes two devices' labels collide, that is a wart and not an authorization problem — **do not
reintroduce a refusal for it.**

## Traps this session hit, so the next one need not

**A build failure is not a mutation test.** Deleting a line to check a test catches its absence
produced `unused variable` / `unused import` three times — which looks identical to a real failure in
a log and demonstrates nothing. **Mutate a VALUE, not a declaration**: `return true || <original>`.

**A test that mirrors the code passes when the code is wrong.** Written twice this session — once
restating a send-loop condition in the test file, once binding no principal in a test named for
binding one. **Name the predicate in the production file and call it.**

**Read the gate's exit line before acting on it.** One commit went out on a red ladder because the
result was assumed. `make privacy-check` exiting **2** means DID NOT RUN and is never clean —
usually because the sweep ran before the commit.

**Resolving a rebase conflict by deleting marker lines by number takes a brace with it.** It failed
loudly here, which was luck; canon's warning is that a wrong resolution ships a silent revert. After
resolving, **run both sides' tests by name** rather than trusting a green ladder.

**Apostrophes in prose break single-quoted awk.** Splice from a file.
